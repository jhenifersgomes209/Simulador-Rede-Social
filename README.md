# Simulador de Rede Social

Projeto da disciplina de Teoria dos Grafos - Grupo 02.

## Tecnologias
- Python
- Streamlit
- NetworkX
- Matplotlib

## Funcionalidades
- Cadastro de usuários
- Criação de amizades
- Visualização de grafos
- Cálculo do grau dos vértices
- Busca em largura (BFS)
- Identificação do menor caminho entre usuários

## Como executar

Instalar dependências:
python -m pip install -r requirements.txt

Executar:
python -m streamlit run app.py
